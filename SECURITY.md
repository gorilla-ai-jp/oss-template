# Security Policy

## 脆弱性の報告 / Reporting a Vulnerability

セキュリティ上の問題を発見した場合は、公開の Issue には書かず、次のいずれかの方法でご報告ください。

If you discover a security issue, please do not open a public issue. Report it through one of the following channels instead.

- このリポジトリの **Security** タブから「Report a vulnerability」(GitHub Private Vulnerability Reporting)
- https://gorilla-ai.jp/contact

報告を受け取ったら、原則 5 営業日以内に一次返信します。修正が完了し公開するまで、詳細を非公開にしていただくようお願いします。

We aim to acknowledge reports within 5 business days. Please keep the details confidential until a fix has been released.

## 対象バージョン / Supported Versions

最新のリリースのみがセキュリティ修正の対象です。
Only the latest release receives security fixes.
